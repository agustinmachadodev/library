# Library - The Odin Project

## Descripción
Proyecto de The Odin Project de una libreria 

Aplicación web permite:
- Visualizar libros en forma de tarjetas.
- Mostrar información como título, autor, número de páginas y estado de lectura.
- Agregar nuevos libros mediante un formulario. **(Proximamente)**
